# ASSETS.md — Twice-Told Tale

Asset manifest. The game now ships with **complete, original, copyright-free
art** (backgrounds/CGs procedurally generated by `tools/make_art.py`; sprites
sliced from hand-supplied expression sheets by `tools/import_sheets.py`) and a
**CC0 soundtrack** (fetched by `tools/fetch_music.sh` / `tools/fetch_sfx.sh`; see
`game/audio/CREDITS.md`). Every asset is a drop-in placeholder for hand-made
work of the same name.

## Conventions

| Item | Spec |
|------|------|
| Base resolution | **1280 × 720** (16:9), virtual; art drawn at 2× for crispness |
| Backgrounds | **1920 × 1080** PNG or WebP, full-bleed (no letterboxing) |
| CGs | **1920 × 1080** PNG or WebP, full-bleed |
| Sprites | **~760 px tall** at 720p (≈1600–1900 px tall at 2×), transparent PNG |
| Sprite anchor | feet at the bottom edge; drawn to sit on the say-box line |
| Sprites | facing slightly toward centre; consistent light direction |
| Audio (music) | `.ogg` Vorbis, loopable, −16 LUFS integrated |
| Audio (SFX) | `.ogg` Vorbis, normalized to ~−6 dBFS peak |
| Fonts | Cinzel Decorative (display) + Crimson Text (body/UI), OFL-1.1; Hassengard (logo lockup), freeware **non-commercial** — `game/gui/fonts/` |

Replacing a placeholder: drop the matching file in place and update
`game/images.rpy` (auto-generated by `tools/make_art.py --rpy`) to point at it,
e.g.

```renpy
image bg annex_night = "images/bg/annex_night.png"
image wanderer neutral = "images/sprites/wanderer_neutral.png"
image cg folio_page = "images/cg/folio_page.png"
```

Recommended folders: `game/images/bg/`, `game/images/sprites/`, `game/images/cg/`.

## Generated art (`tools/make_art.py`)

All **backgrounds and CG plates** are produced procedurally in a consistent
"ink & paper" style (layered painterly washes, silhouettes, atmosphere).
Character sprites are **not** generated — they are sliced from hand-supplied
expression sheets by `tools/import_sheets.py` (see below). Background/CG output
is deterministic. Re-run to regenerate:

```sh
python3 tools/make_art.py            # bg + CG plates -> game/images, then images.rpy
python3 tools/make_art.py --bg --cg  # just plates
python3 tools/make_art.py --montage  # contact sheet at tools/out/montage.png
python3 tools/import_sheets.py --install   # re-slice the expression sheets
```

- Backgrounds/CGs: `game/images/bg/*.png`, `game/images/cg/*.png` (1920×1080 PNG,
  full-bleed; the engine scales them to the 1280×720 virtual frame)
- Sprites: `game/images/sprites/<tag>_<expr>.png` (700×1120 sheet canvas,
  transparent), cut by `tools/import_sheets.py`; standing figures are ~950 px of
  opaque content so every character shares one eye line
- Image registry: `game/images.rpy` (do not hand-edit; re-run `make_art.py --rpy`)
- In-scene figures on the CG plates are dark silhouettes cut from the installed
  sprites, so they always match the character art.

Placeholder image keys currently registered: `image (<tag>, "<expression>")`.

**Special cases**
- All eight sprite sets are cut from hand-supplied expression sheets by
  `tools/import_sheets.py`.  Source: `~/Downloads/sprite_clean/sprite/<tag>.png`
  (redrawn transparent sheets for wanderer/echo/nahida/dottore/tighnari come
  from `~/Downloads/better sprite.tar`) — one PNG per character holding a grid
  of expressions.  The importer finds cell gaps from the alpha projection,
  strips any text labels above a head, trims to the alpha bbox and scales to the
  standard 700×1120 canvas.  Opaque (flat/white) sheets are background-keyed
  automatically by `remove_flat_bg`.  The importer owns `game/images/sprites/`;
  `make_art.py` no longer generates sprites at all.
  The Echo arrives as two uncaptioned 4-pose rows supplied as white-background
  WhatsApp sheets: `echo.png` = `amused, smile, cold, sneer` and `echo1.png` =
  `grieving, startled, shy` (a second `startled` blank in the source row is
  unused); figures are cropped to their alpha bbox and the flat background is
  knocked out by `remove_flat_bg`.
  `wanderer guarded` is absent from the new sheet, so it is copied from `smug`.
  `cyno` uses a dedicated white-background JPEG (`~/Downloads/cyno.jpeg`,
  `cut=True` in the importer) instead of the sheet.  The importer resizes in
  premultiplied alpha so transparent-black can't bleed into the edge; it
  deliberately applies no sharpening, since an unsharp mask only exaggerates
  the cut edge into a halo.
- The Puppet and The Boy (Wanderer's past forms) have no sprite yet — either a
  dedicated sprite or handled entirely in CG. See Page-Walk acts.
- Escher (Dottore in disguise) can reuse the `dottore` sprite with a costume
  variant.
- Paimon's sprites were removed — she does not appear in the finalized script
  and has no dialogue, so no sprite set exists.

### Sprite staging (`game/screens_extra.rpy`)

Five standing slots (`at_far_left` 0.02, `at_left` 0.22, `at_center` 0.5,
`at_right` 0.78, `at_far_right` 0.98). The Echo always stages on the left and
the Wanderer on the right; right-side slots mirror (negative `xzoom`) to face
centre. Each slot glides in from its own side (a one-shot `on show` slide plus
fade) and glides back out `on hide`, then settles into a slow idle breath.
