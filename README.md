# Twice-Told Tale

A 30-day otome visual novel in which **Scaramouche** and the **Wanderer** exist
at the same time. You keep a magical Folio that writes what happens as it
happens — and the page always asks the same question: *who gets to hold the pen?*

Built with [Ren'Py](https://www.renpy.org/). The story branches across four acts
(plus a prologue) and reaches **ten endings**, tracked in a persistent gallery.

This is a private, non-commercial fan work. Genshin Impact and its characters
belong to their respective owners; this project is not affiliated with HoYoverse.

## Running the game

1. Install [Ren'Py 8.5+](https://www.renpy.org/latest.html).
2. Open the Ren'Py launcher, point it at this folder, and choose **Launch
   Project** — or from a terminal:

   ```sh
   /path/to/renpy.sh /path/to/Twice-told-tale
   ```

To build desktop distributions, use the launcher's **Build Distributions** page
(assets are archived; see `game/options.rpy`).

## Controls

| Action | Keyboard | Mouse |
|--------|----------|-------|
| Advance dialogue | `Space` / `Enter` | Left click |
| Skip | `Tab` (hold `Ctrl` to skip faster) | Skip button |
| Auto-advance | `A` | Auto button |
| Rollback | `Page Up` | Mouse wheel up |
| Menu | `Esc` / right click | — |
| Fullscreen | `F` / `Alt+Enter` | — |

Scene-title cards can be clicked through. Choices are irreversible per run;
progress is saved normally, and the endings/CG/music galleries persist across
every playthrough.

## What's in the menus

- **Start** — begin a new playthrough.
- **Pages Collected** — the ten endings, each unlocked as you reach it.
- **Gallery** — every CG illustration you've seen.
- **Music Room** — the score, one cue per track once you've heard it.
- **Credits** — the roll.
- **About / Help / Preferences / Save / Load** — the usual Ren'Py screens.

## Regenerating assets

Backgrounds and CG plates are procedurally generated (no third-party images) and
the generation is **deterministic** — re-running reproduces byte-identical files.
Character sprites are sliced from hand-supplied expression sheets.

```sh
python3 tools/make_art.py            # backgrounds + CG plates + images.rpy
python3 tools/make_art.py --cg       # only the CG illustrations
python3 tools/make_art.py --only sleeping_puppet raiden_yae
python3 tools/make_art.py --montage  # write tools/out/montage.png contact sheet
python3 tools/import_sheets.py --install   # slice the expression sheets into sprites
```

Audio is fetched from OpenGameArt (all CC0) and normalized to Ogg Vorbis:

```sh
bash tools/fetch_music.sh
bash tools/fetch_sfx.sh
```

Requires Python 3 with Pillow + NumPy, ImageMagick (`montage`), and `ffmpeg`.
See `ASSETS.md` for the full manifest and how to drop in your own art.

## Tests

Ren'Py ships a headless test runner. Lint first, then run the suites:

```sh
renpy.sh . lint
renpy.sh . test smoke
renpy.sh . test draft
renpy.sh . test galleries
renpy.sh . test progress
renpy.sh . test catalogues # opens Pages/Gallery/Music Room/Credits from the menu
renpy.sh . test route      # walks Acts 2-4 to the Archivist's Fee ending
renpy.sh . test endings    # visits every ending label
renpy.sh . test gates      # unit-checks the ending-gate functions
```

Each `test` invocation runs a single named testcase.
